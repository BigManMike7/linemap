LineMap

Door-line wait times for State College bars.

How it works

People in line tap Start when they join the line outside and Stop when they get past the ID check. LineMap combines recent reports into a wait estimate for each bar: under 5, 5-15, 15-25 or 25+ minutes. If no one has reported recently, it says so instead of guessing.
